# nonnon

An offline-first English learning app for Android 9+.

## Build
GitHub Actions builds a debug APK on every push to `main` and supports manual runs. Download **nonnon-debug-apk** from the workflow run's Artifacts section.

## App
- Persian-first interface and pink / purple visual identity
- Six CEFR stages, lesson path, interactive quizzes, vocabulary review
- Local progress, XP, hearts, streak and daily goal
- Android Text-to-Speech pronunciation support

The first release contains a playable A1 starter course. The remaining CEFR units are structured as the learning path and will be populated with reviewed lesson content in subsequent releases.
